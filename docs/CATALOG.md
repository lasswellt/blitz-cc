## Workflows

| Workflow | Description |
|---|---|
| `/blitz:audit-sweep` | 5-pillar audit: 2 independent same-scope agents per pillar, one parallel() barrier (audit §1.1-W) |
| `/blitz:build-wave` | Dispatch one wave of blitz dev agents in isolated worktrees (build --parallel §Wave) |
| `/blitz:review-fanout` | Parallel or sequential critic --mode survey lenses plus the adversarial critic --mode reject (check Phases 2.1 and 4.3) |
