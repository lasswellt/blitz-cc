## 0. How to read a profile

Each profile fills the §4 contract: `detection` · `authoringSurface` · 7 facet resolvers · `runtimeThemingApi` · `darkMode` · `conformanceRules` (Layer 2) · `reconciliations`. Per-source citations are in §6. A profile is the single place a stack's specifics live; the spine and detector stay stack-agnostic.

**Decision applied (this pass):** the **Vuetify profile targets v4 as primary** (current stable since 2026-02-23), with **v3** and **v0** as tracked variants. Rationale in §3.

## 1. Tailwind v4 (plain)

- **id:** `tailwind` · **primaryOf:** components? no — utility-only; primary only when no component framework present · **secondaryAllowed:** yes (layout/spacing layer on Vuetify; **never** on Quasar — §4 incompat).
- **detection:** dep `tailwindcss@^4`; `@import "tailwindcss"` + `@theme {` in CSS; **absence of `tailwind.config.js` is normal** (CSS-first). v3 discriminator: `@tailwind base` + `tailwind.config.{js,ts}`.
- **authoringSurface:** `@theme { … }` blocks in CSS (top-level vars; compile to `:root` custom properties **and** generate utilities). `@theme inline` for aliasing; `@theme static` to force-emit; `--*: initial` to reset a namespace.

**Facet resolvers**

| Facet | Resolution |
|---|---|
| colorRoles | `--color-*` namespace → `bg-*`/`text-*`/`border-*`/`ring-*`/… **open convention, no semantic roles** (palette only: 50–950 OKLCH; +mauve/olive/mist/taupe in v4.2). `closedSet: false`. |
| onPairing | **computed-fallback** — no native `on-*`; teams alias `--color-on-primary` by hand; contrast is the dev's responsibility → the `visual` engine checks it. |
| typeScale | `--text-xs…9xl` (each with paired `--text-*--line-height`); `--font-weight-*`, `--tracking-*`, `--leading-*`. `fixedByFramework: false`. |
| shape | `--radius-xs…4xl`; **v3→v4 scale shift** (`rounded`→`rounded-sm`, `rounded-sm`→`rounded-xs`). |
| motion | `--ease-{in,out,in-out}` (ease-out default); custom `--ease-*` idiomatic; `--animate-{spin,ping,pulse,bounce}`. `springPrescribed: false`. |
| spacing | `--spacing` scalar → every spacing/sizing utility; container queries built-in (`@sm:`, `@container`). |
| elevation | `--shadow-2xs…2xl` + inset/drop; **no semantic elevation abstraction** — choose a shadow utility directly. |

- **runtimeThemingApi:** override `:root` custom properties at runtime (CSS rule or `style.setProperty`); `getComputedStyle()` to read (no `resolveConfig` in v4).
- **darkMode:** `dark:` variant — `prefers-color-scheme` by default, or `@custom-variant dark (&:where(.dark, .dark *))` for class/attribute control.
- **conformanceRules (Layer 2):** legacy v3 classes (`bg-gradient-to-*`→`bg-linear-to-*`, `shadow-sm`/`rounded` scale shift, `bg-[--var]`→`bg-(--var)`, `!flex`→`flex!`, `@tailwind base`→`@import`, `bg-opacity-*`→`/50`); arbitrary `[#hex]` where a token exists (advisory); extensive `@apply` in `@layer components` (advisory — v4 favors components); raw `box-shadow:`/`border-radius:`/`color:#hex` in CSS when a `--shadow/--radius/--color` token exists.
- **reconciliations:** `bounceEasing: keep` · `ghostCardElevation: relax` (border+`shadow-md` idiomatic) · `radiusCap: defer→--radius-*` · `rawColorLiteral: keep` (`[#hex]` advisory).

## 2. Tailwind + MD3 (composite token layer)

MD3 is **not a primary** — it is a token layer over Tailwind v4. The composite adapter = Tailwind surface + MD3 role conformance.

- **detection:** Tailwind detected **AND** any MD3 marker: `--md-sys-*` custom properties; dep `@material/web` / `@material/material-color-utilities`; `<md-*>` web-component tags; an MD3-mapped `@theme` (`--color-primary: var(--md-sys-color-primary)`); `applyTheme()` calls.
- **authoringSurface:** `--md-sys-*` CSS custom properties on `:root` (generated by Material Theme Builder / `material-color-utilities.themeFromSourceColor()`), **bridged** into Tailwind via `@theme` aliasing. Three tiers: `--md-ref-*` (raw) → `--md-sys-*` (semantic) → `--md-comp-*` (per-component).

**Facet resolvers**

| Facet | Resolution |
|---|---|
| colorRoles | **49 sys-color tokens** — `--md-sys-color-{primary,secondary,tertiary,error}` (+ `-container`, `-fixed`, `-fixed-dim` + `on-*` for each), `surface` + `surface-container-{lowest,low,_,high,highest}`, `surface-variant`, `outline`, `outline-variant`, `inverse-*`, `shadow`, `scrim`. `closedSet: true`. |
| onPairing | **enforced-by-role** — every container/bg role has `--md-sys-color-on-<role>` at WCAG-AA. (surface-container-* share `on-surface`/`on-surface-variant`; fixed roles use `on-*-fixed`/`-fixed-variant`.) |
| typeScale | **15-role scale** `--md-sys-typescale-{display,headline,title,body,label}-{large,medium,small}-{font,size,line-height,weight}` + 2 `weight-prominent`. **Tracking unsupported on web.** |
| shape | **7 corners** `--md-sys-shape-corner-{none,extra-small,small,medium,large,extra-large,full}` (0/4/8/12/16/28dp/pill). M3 Expressive adds +35 shapes (design lib; core 7 unchanged on web). |
| motion | `--md-sys-motion-easing-{standard,emphasized,emphasized-accelerate,emphasized-decelerate,legacy*}` + `--md-sys-motion-duration-{short1..4,medium1..4,long1..4,extra-long1..4}` (50–1000ms). M3 Expressive **spring prescribed** but **CSS spring tokens not yet shipped on web** — `emphasized-*` overshoot curves are today's expression. `springPrescribed: true (spec); web-pending`. |
| spacing | inherits Tailwind spacing; MD3 has no separate web spacing-token scale. |
| elevation | **levels 0–5**; expressed two ways — **tonal** (`surface-container-*` hierarchy, the *preferred* M3 direction) and **shadow** (`<md-elevation>` reading `--md-elevation-level` integer). `surface-tint` overlay is transitional/deprecating. |

- **runtimeThemingApi:** `material-color-utilities.applyTheme()` writes `--md-sys-color-*` to the DOM (dynamic color from a source color); `--md-sys-*` remain the runtime source of truth behind the `@theme` bridge.
- **darkMode:** MD3 dark scheme = remap `sys`→`ref` (sys tokens point at lighter ref tones in dark).
- **conformanceRules (Layer 2):** all Tailwind rules **plus** MD3-role conformance — raw color vs a `--md-sys-color-*` role; type size vs the 15-role scale; radius vs the 7 corner tokens; elevation vs levels 0–5 (prefer tonal `surface-container-*`); `@theme` bridge present when MD3 tokens used with Tailwind utilities.
- **reconciliations:** `bounceEasing: relax` (M3 Expressive spring; `emphasized-decelerate: cubic-bezier(0.05,0.7,0.1,1)` overshoots — cite the prescription) · `ghostCardElevation: relax` (tonal surface / `<md-elevation>` multi-layer shadow at levels 3–5) · `radiusCap: defer→corner tokens (≤28dp + full pill)` · `rawColorLiteral: keep`. Also relax: integer `--md-elevation-level` (not a missing-unit error); `linear` easing (official MD3 token).

## 3. Vuetify (v4 primary; v3 + v0 tracked)

- **detection:** dep `vuetify` → variant by range (`^4`→**v4**, `^3`→**v3**); `@vuetify/v0`→**v0**; `createVuetify(` in source; `src/plugins/vuetify.{ts,js}`; co-dep `@mdi/font`/`@mdi/js`.
- **authoringSurface:** `createVuetify({ theme: { defaultTheme, themes: { light/dark: { dark, colors{}, variables{} } }, variations } })` — JS/TS config.

**Facet resolvers (v4 canonical; v3 delta noted)**

| Facet | v4 (canonical) | v3 delta |
|---|---|---|
| colorRoles | `primary`/`secondary`/`surface`/`background`/`error`/`info`/`success`/`warning` + `surface-{bright,light,variant}`; **no `accent`** (v2 concept) | same set |
| onPairing | **enforced-by-role** — auto-generated `on-<color>` per `colors` key (incl. custom); `text-on-*` classes | same |
| colorOutput | `--v-theme-*` (RGB triplet, no wrapper) → `rgb(var(--v-theme-primary))`; `text-*`/`bg-*`/`text-on-*` classes. **v4: `rgba(var(--v-theme-*),a)` breaks for transparent colors → use `color-mix()`** | v3: `rgba(var(--v-theme-*),a)` valid |
| typeScale | **MD3 names** (`text-display-large`…`text-label-small`); button/overline not uppercased by default | v3: **MD2** (`text-h1..h6`, `subtitle-1/2`, `body-1/2`, `button`, `caption`, `overline`) |
| shape | `rounded` prop (0/sm/md/lg/xl/pill/circle) + `rounded-*` utils (lg=8px, xl=24px); `$border-radius-root 4px` | same |
| motion | MD-canonical `$standard`/`$decelerated`/`$accelerated` easing (**no bounce/spring**); 15 `v-*-transition` components; `createCssTransition()` | same |
| elevation | **0–5 (MD3)** | **v3: 0–24 (MD2)** — `elevation` prop + `elevation-*` |

- **runtimeThemingApi:** `useTheme()` — `theme.global.name.value = 'dark'`, `theme.toggle()`/`change(name)`/`cycle()`; mutate `theme.themes.value.<name>.colors.*` at runtime; all reactive. Component-scoped `<v-card theme="dark">` / `<v-theme-provider>`.
- **darkMode:** per-theme `dark: true|false`; `'system'` reserved (OS `prefers-color-scheme`). **Default: `system` (v4) / `light` (v3).**
- **conformanceRules (Layer 2):** hardcoded color in components/templates (use `rgb(var(--v-theme-*))`) — **but exempt the `colors{}` theme config**; `!important` fighting component defaults (KEEP flagging — use props/theme/SASS instead); v4: `rgba(var(--v-theme-*),a)` syntax (flag → suggest `color-mix()`); v3-only elevation > 5 valid (0–24).
- **reconciliations:** `bounceEasing: keep` (built-ins use non-oscillating MD curves — no exemption needed) · `ghostCardElevation: relax` (`elevation` prop/`elevation-*`) · `radiusCap: defer→rounded scale` · `rawColorLiteral: keep` (theme `colors{}` is the legitimate literal home).
- **v0 forward-compat (alpha):** `@vuetify/v0`, `--v0-*` prefix, `createThemePlugin`, unopinionated, ships Material/Tailwind/Radix/Ant palettes. **Distinct ruleset — do NOT apply v3/v4 rules to v0 code.** Profile tracks it; canonical guidance stays v4 until v0 stabilizes.

## 4. Quasar 2

- **detection:** dep `quasar@^2`; `quasar.config.{js,ts}`; `src/css/quasar.variables.scss`; devDep `@quasar/app-vite`/`@quasar/app-webpack`/`@quasar/vite-plugin`.
- **authoringSurface:** `src/css/quasar.variables.scss` — redefine `!default` SCSS variables (auto-imported when the file contains `$`). Compiled into component CSS at build; `--q-*` custom properties emitted on `document.body`.

**Facet resolvers**

| Facet | Resolution |
|---|---|
| colorRoles | **8 brand:** `$primary`/`$secondary`/`$accent`/`$dark`/`$positive`/`$negative`/`$info`/`$warning` (+ `$dark-page`); 24 palette families × 14 shades (`$red-1..14`). `closedSet: true` (brand). |
| onPairing | **computed-fallback** — no `on-*` token system; component-internal contrast text. |
| typeScale | `text-h1..h6`/`subtitle1/2`/`body1/2`/`caption`/`overline`; `text-weight-*`; `$body-font-size 14px`; Roboto default (optional). |
| shape | `$generic-border-radius 4px` + `.rounded-borders`. |
| motion | **Animate.css integration** (80+ classes incl. `bounceIn/Out`, `fadeIn`, …; `animated` prefix required); `$animate-duration .3s`. No prescribed CSS easing token. |
| spacing | `$space-*` SCSS map + `q-pa-*`/`q-ma-*`/`q-gutter-*` helpers; `dense` props. |
| elevation | **`shadow-1..24` + `shadow-up-1..24`** (MD 24-level) + `inset-shadow`/`no-shadow`/`shadow-transition`. Prescribed. |

- **runtimeThemingApi:** `setCssVar(name,val)` / `getCssVar(name)` / `getPaletteColor(name)` + `colors` utils (`lighten`/`blend`/`changeAlpha`/…).
- **darkMode:** `$q.dark` plugin (`.isActive`/`.set('auto'|true|false)`/`.toggle()`); adds `body--dark` class → style with `.body--dark {}`. SSR: avoid `'auto'` (hydration flicker).
- **conformanceRules (Layer 2):** raw inline hex outside `quasar.variables.scss` (use `bg-primary`/`setCssVar`); **Tailwind-coexistence WARNING** (see below); color outside the 8 brand + palette vocabulary; type/shape/elevation must use Quasar's classes.
- **reconciliations:** `bounceEasing: relax` (Animate.css `bounceIn/Out` are vocabulary — cite) · `ghostCardElevation: relax` (`shadow-1..24`) · `radiusCap: defer→$generic-border-radius` · `rawColorLiteral: keep` (`quasar.variables.scss` is the literal home; inline hex flagged).
- **Tailwind incompatibility (hard):** Quasar does **not** use Tailwind. Co-install → class collisions (`.flex`/`.block`/`.hidden`/…) + unlayered-CSS specificity war; Quasar overrides Tailwind on `<q-*>`. Selector emits `incompatibilities: ["quasar+tailwind"]`, never `secondary`. The pillar must not recommend Tailwind theming on Quasar.

## 5. Cross-adapter summary

| Property | Tailwind v4 | Tailwind+MD3 | Vuetify v4/v3 | Quasar 2 |
|---|---|---|---|---|
| Color roles | open palette | 49 closed MD3 | 8 named + auto-variant | 8 brand + palette |
| `on-*` | computed | enforced | enforced (auto) | computed |
| Elevation | shadow utils | 0–5 + tonal | 0–5 / 0–24 | shadow-1..24 |
| `bounceEasing` | keep | **relax** | keep | **relax** |
| Tailwind layering | n/a | composite | secondary OK | **incompatible** |
| Runtime theming | CSS-var override | `applyTheme()` | `useTheme()` | `setCssVar()` |
